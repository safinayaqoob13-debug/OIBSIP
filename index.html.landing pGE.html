Oasis Infobyte Web Dev & Design • Level 1 Task 1

Project Overview

Velora Beauty is a modern, elegant, and fully responsive landing page for a fictional cosmetics brand created as Level 1 Task 1 for the Oasis Infobyte Web Development and Designing Internship.

Technologies Used

  • HTML5: Semantic markup (`header`, `section`, `nav`, `footer`, `article`).
  • CSS3 / Tailwind: Advanced Flexbox and CSS Grid alignments, custom color palettes (blush pink, ivory, rose-gold), media queries, and smooth transition effects.
  • Google Fonts & FontAwesome: Playfair Display & Inter typography combined with professional iconography.

Key Features

  • Sticky Navigation Bar with mobile hamburger toggle.
  • Engaging Hero section featuring high-end Unsplash imagery and clear CTA.
  • Featured Products grid showcasing 4 bestselling skincare items with ratings and pricing.
  • Promotional Banner and About section highlighting quality ingredients and gentle skincare.
  • Responsive Footer with contact information, quick links, newsletter form, and social icons.

Instructions to Run Locally

  1. Save the code into a single file named index.html.
  2. Open the file in any modern web browser (Chrome, Safari, Firefox, Edge).
